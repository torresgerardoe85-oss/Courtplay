# CourtPlay — Prototype v1

Primera versión funcional pensada para iPad.

Incluye:
- Media cancha editable.
- 5 jugadores + balón arrastrables.
- Herramientas de Corte, Pase y Screen.
- Frames duplicables.
- Explicación y duración por frame.
- Reproducción automática.
- Guardado local en el dispositivo.
- Exportación PNG con explicación.
- Exportación de video cuando Safari/navegador permite MediaRecorder + canvas capture.
- El texto del video cambia automáticamente al cambiar de frame.
- PWA/offline básico cuando se publica bajo HTTPS.

## Para probar rápido
1. Abre CourtPlay desde la URL de GitHub Pages.
2. En iPad: Safari > Compartir > Añadir a pantalla de inicio.
